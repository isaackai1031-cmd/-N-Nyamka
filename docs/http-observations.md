# HTTP ажиглалт (L14)

Эх сурвалжийг "Өгөгдөл ачаалах" хэсгээс сонгоод **Ачаалах** дарна. Console (F12)-ийг нээлттэй байлгана.

## 5 төлөвийн үр дүн
| Эх сурвалж | HTTP | Аль алхамд баригдсан | UI төлөв | UI мессеж |
|------------|------|----------------------|----------|-----------|
| `data/products.json` | 200 | — | success | "5 бараа ачааллаа." |
| `data/empty.json` | 200 | — (`[]`) | empty | "Бараа бүртгэгдээгүй байна." |
| `data/missing.json` | **404** | `response.ok === false` | error | "HTTP алдаа 404: өгөгдөл олдсонгүй." |
| `data/broken.json` | 200 | `response.json()` throw | error | "Өгөгдлийн формат буруу (JSON уншиж чадсангүй)." |
| `127.0.0.1:59999` (сервер байхгүй) | — (хариу ирээгүй) | `fetch()` reject | error | "Сүлжээний алдаа: сервертэй холбогдож чадсангүй." |

Ачаалж байх үед "Ачаалж байна…" гарч, **Ачаалах** товч идэвхгүй болно (loading).

## Console-д гарсан
```
[http error] 404 data/missing.json
[parse error] Expected ',' or '}' after property value in JSON at position 43
[network error] Failed to fetch
```

## Гол ажиглалтууд
1. **`fetch` 404 дээр reject хийдэггүй.** Сервер хариу өгсөн тул fetch "амжилттай" гэж үзнэ. Тиймээс `response.ok`-ийг өөрсдөө шалгах шаардлагатай. Шалгахгүй бол 404 хуудасны агуулгыг JSON гэж уншиж, буруу алдаа гарна.
2. **Дараалал:** эхлээд `response.ok`, **дараа нь** `response.json()`. Эсрэгээр нь хийвэл 404-ийн HTML хуудас parse алдаа болж, жинхэнэ шалтгаан (404) нуугдана.
3. **Status алдаа ≠ parse алдаа.** broken.json нь 200 буцаасан ч агуулга нь эвдэрсэн байна. Энэ хоёрыг тусдаа `try` блокоор ялгасан.
4. **Хоосон (empty) ≠ алдаа (error).** `[]` бол амжилттай хариу, зүгээр л бараа байхгүй гэсэн үг. Хэрэглэгчид өөр мессеж харуулна.
5. **Network error** нь сервер хариу огт өгөөгүй үед гарна. Энэ үед `response` объект байхгүй тул status ч байхгүй.

## Promise ба await: 3 үйл явдлаар
1. `fetch(url)` дуудахад шууд **Promise** (ирээдүйн хариуны амлалт) буцна. Хүсэлт ар талд явж, хуудас хөлдөхгүй.
2. `await fetch(url)` нь сервер **хариу толгойг** (status) өгөх хүртэл энэ функцийг түр зогсооно. Энэ хооронд хэрэглэгч хуудсан дээр ажилласаар байна.
3. `await response.json()` нь хариуны **биеийг** бүрэн уншиж JSON болгох хүртэл дахин хүлээнэ. Тиймээс энэ нь хоёр дахь, тусдаа алдаа гарч болох алхам юм.
