## Тайлбар
- **Хоосон массив = 0** нь зөв үр дүн. Хөдөлгөөнгүй бараа 0 үлдэгдэлтэй (AC-08.2).
- **Type coercion:** `"10" + "5"` нь `"105"` болдог, учир нь `+` нь текстийг залгадаг. `Number("10") + Number("5")` = 15. Гэхдээ `Number()` нь `"abc"`-г `NaN` болгодог тул хөрвүүлэхээс илүү **typeof-оор шалгаж татгалзах** аргыг сонгосон.
- **Number ба validation-ийн ялгаа:** `Number()` нь утгыг хөрвүүлдэг. Validation нь утга зөв эсэхийг шалгаад буруу бол татгалздаг.
- **Эх өгөгдөл:** `sort()` эх массивыг өөрчилдөг тул `[...list]` хуулбар дээр эрэмбэлсэн. `filter()` нь өөрөө шинэ массив буцаадаг.
