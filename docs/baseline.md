# Базис ойлголт — Хүнсний агуулах

## Бизнесийн жишээ: орлого, зарлага, үлдэгдэл

Жишээ бараанууд:
- SKU: MILK-01 "Сүү (1л)" — үлдэгдэл 24
- SKU: NUT-01 "Самар (жилэнгийн 500г)" — үлдэгдэл 10
- SKU: BREAD-01 "Талх (350г)" — үлдэгдэл 30
- SKU: EGG-01 "Өндөг (10 ширхэг)" — үлдэгдэл 15
- SKU: RICE-01 "Будаа (5кг)" — үлдэгдэл 8

### Жишээ тохиолдол: Хэвийн
Нярав 6 ширхэг MILK-01 сүүний орлого батлав.
Өмнө 24 байсан бол 30 болно. Үлдэгдэл 30, зөв төлөвтэй.

### Жишээ тохиолдол: Хил зааг
Агуулахаас 8 ширхэг RICE-01 будааг зарлагадна. Үлдэгдэл 0 болно.
Үлдэгдэл 0 нь зөв төлөв байх боломжтой (хоосон агуулах).

### Жишээ тохиолдол: Алдаа
Агуулахаас 11 ширхэг RICE-01 зарлага хүсэв.
Татгалзсан (409), үлдэгдэл 8 хэвээр. Татгалзсан үед өөрчлөгдөхгүй.

## Шалгах асуулт (хариу бүү бич — асуултаа нэмээрэй)
- Хоёр хуснэгтийн холбоос бүхий SQL асуултын үр дүнг гаргаарай:
  "Ямар хүнс, хэдэн ширхэг үлдэгдэлтэй байгааг бараа + үлдэгдэл
  хүснэгтээс нэгдэн гаргаж үзүүл."
  
  // 1. Массив үүсгэх
  const products = [ ... ];
const products = [
  { sku: "MILK-01", name: "Сүү (1л)", qty: 24 },
  { sku: "NUT-01", name: "Самар (жилэнгийн 500г)", qty: 10 },
  { sku: "BREAD-01", name: "Талх (350г)", qty: 30 },
  { sku: "EGG-01", name: "Өндөг (10 ширхэг)", qty: 15 },
  { sku: "RICE-01", name: "Будаа (5кг)", qty: 8 },
];

// 2. Хамгийн бага утга хадгалах хувьсагчууд
let minQty = Infinity;
let minProduct = null;

// 3. Давталтаар бүрийг харьцуулах
for (const p of products) {
  // 4. Илүү бага бол шинэ мин болгож, барааны мэдээллийг хадгалах
  if (p.qty < minQty) {
    minQty = p.qty;
    minProduct = p;
  }
}

// 5. Хэвлэх
console.log(`${minProduct.sku} (${minProduct.qty} ширхэг)`);
